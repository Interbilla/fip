# Contributing

We welcome counterexamples, independent implementations, conformance reports,
semantic gaps, ambiguities, and adversarial results.

1. Reproduce the issue with public synthetic data.
2. State whether it is a clarification, implementation bug, conformance bug,
   primitive/relation proposal, semantic-rule proposal, domain extension, or
   architecture proposal.
3. Run `make test` and include results.
4. Keep domain-specific concepts outside FIP unless the gap cannot be expressed
   using the frozen vocabulary.

FIP 0.1 semantics are frozen. Semantic changes belong in a future candidate.
By contributing, you agree that your contribution is licensed under Apache-2.0.

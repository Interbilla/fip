# Security policy

FIP 0.1 is experimental research software, not a production-certified security
control. Report semantic bypasses and implementation vulnerabilities with a
minimal synthetic reproduction, affected version, expected/actual decision,
and whether an operational effect occurred.

Send sensitive reports to `info@interbilla.com`. Include only the information
needed to reproduce and assess the issue. Do not disclose sensitive exploit
details publicly before the maintainers have had a reasonable opportunity to
investigate.

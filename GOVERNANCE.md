# Governance

FIP 0.1 is frozen as a Reference Candidate. Reports are triaged as clarification,
implementation bug, conformance bug, new primitive, new relation, semantic rule,
domain extension, or architecture proposal. Clarifications cannot change frozen
behavior. Semantic changes require a new version such as 0.2, documented rationale,
new/updated vectors, and explicit compatibility analysis. GOCP and firewall
proposals are architecture work and do not automatically change FIP vocabulary.

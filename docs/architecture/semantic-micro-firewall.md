# Semantic Micro-Firewall

A Semantic Micro-Firewall is a policy-evaluation boundary that determines
whether a consequential semantic interaction is sufficiently specified and
authorized to acquire operational effect. Its decisions are `PERMITTED`,
`DENIED`, `INCOMPLETE`, and `ESCALATE`.

It is not a replacement for a network firewall, identity provider, policy
engine, or application authorization system. The reference evaluator is minimal
research software.

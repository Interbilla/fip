# FIP 0.1 Reference Candidate

FIP represents governed consequential interactions independently of application
ontologies. An exchange identifies its semantic act and relevant actor, resource,
action, purpose, authority, authorization, scope, validity, evidence, provenance,
policy, and normative state. Required fields depend on the semantic act.

The normative executable behavior for 0.1 is the frozen reference adapters plus
the 47 conformance vectors. This document is explanatory and cannot silently
change them. See [primitives](primitives.md), [relations](relations.md), and
[semantic rules](semantic-rules.md).

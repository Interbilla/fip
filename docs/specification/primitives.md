# Canonical primitives

FIP 0.1 freezes exactly 26 primitives:

Actor, Resource, Role, Identity, Credential, Request, Response, Action,
Assertion, Recommendation, Instruction, Delegation, Decision, Purpose,
Condition, Constraint, Authority, Authorization, Permission, Prohibition,
Obligation, Policy, Evidence, Provenance, Validity, and Scope.

These are interaction concepts, not a complete domain ontology.

# Limitations

FIP 0.1 is a Reference Candidate under bounded internal evaluation. It is not a
standard, proof of minimality or completeness, universal ontology, formal
verification, production certification, prompt-injection defense, or safety
guarantee. External organizational validation has not been claimed.

The generative protected experiment covered 33 episodes. Its B1 feedback had
only one outcome tuple, which may have reduced adversary adaptivity. Campaigns
with different domains, attackers, and budgets must not be pooled as identical
independent trials. Integration errors and paths outside the enforced gateway
remain important risks.
